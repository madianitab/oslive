Edite o código e clique em Executar (ou Ctrl + Enter).

Cada processo executa até bloquear ou terminar. Na ordem aleatória, a saída pode se intercalar de outro jeito a cada execução: use para ver outra execução possível.

O tempo só avança com sleep(); as demais instruções são instantâneas.
  • fork() getpid() getppid()
  • wait(&st) waitpid(pid, &st, op)
  • sleep(s) exit(n) printf(...)
  • WEXITSTATUS WNOHANG NULL

Também: int/pid_t, vetores, variáveis globais, funções, if, for, while, do e #define. O primeiro processo tem PID {{ pidInicial }}; o limite é {{ limite }} processos.
