Ciclo de cada processo: criação → CPU → CPU → E/S → CPU → fim. A 1ª fase de CPU é maior que o quantum ({{ sim.opcoes().quantum }} u), então o processo usa a CPU duas vezes, voltando à fila de aptos entre elas (preempção). Os valores são sorteados a cada novo cenário.
  • Criação: processo está sendo criado
  • Apto: pronto, na fila esperando a CPU
  • Executando: usando a CPU
  • Bloqueado: esperando um evento (ex.: E/S)
  • Destruição: processo finalizado
