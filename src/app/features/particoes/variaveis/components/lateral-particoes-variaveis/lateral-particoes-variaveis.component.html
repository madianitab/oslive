 Compactar

A compactação desloca os processos para unir as lacunas. Resolve a fragmentação externa, mas gasta CPU e exige relocação dinâmica (as bases mudam).
  • Memória de {{ total }} KB: {{ so }} KB do SO e {{ usuario }} KB para os processos.
  • Cada processo recebe exatamente o que precisa (alocação contígua); a sobra vira uma nova lacuna.
  • Não há fragmentação interna. Pode haver fragmentação externa: memória livre suficiente, mas dividida em lacunas pequenas demais.
  • Processos que não cabem esperam na fila; ao liberar memória, a fila é atendida.
  • Swap-out copia um processo para o disco e libera sua memória; swap-in o traz de volta.
