Sempre 3 processos (A, B e C) com segmentos de tamanhos aleatórios, alocados por best-fit.
  • Memória física de 32 bytes (endereço físico de 5 bits).
  • End. lógico = segmento (2 bits: 00 código, 01 dados, 10 pilha) + deslocamento (4 bits).
  • Se deslocamento < limite: físico = base + deslocamento. Senão, interrupção.
  • Bytes contados a partir de 0: C0 é o deslocamento 0000.
  • Best-fit, segmento a segmento (código, dados, pilha): a menor lacuna que o comporta (empate: menor endereço).
  • Se a memória livre é suficiente, mas nenhuma lacuna comporta um segmento: fragmentação externa.
